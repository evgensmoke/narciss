# Ты Нарцисс! — тесты на нарциссические черты

Сайт на чистом HTML/CSS/JS (без сборки). Вход через Google и сохранение результатов — Firebase (те же настройки, что и раньше). Тексты тестов, оформление и логика лежат в **разных файлах**.

## Что где лежит

| Что нужно сделать | Какой файл открыть |
|---|---|
| Изменить вопросы, ответы, описания результатов | `data/tests/test1.js … test5.js` |
| Добавить новый тест | скопировать `data/tests/_template.js` + одна строка в `data/tests-list.js` |
| Общие итоги по баллам («Выраженные признаки» и т. п.), дисклеймер | `data/config.js` |
| Цвета, шрифты, вид | `css/style.css` |
| Логика сайта (обычно не трогать) | `js/app.js` |
| Админ-почта и ключи Firebase | `js/firebase-config.js` |
| Звуки | `js/sound.js` |
| Картинки (фоны, заставка, инфографика) | `images/` |

## Как редактировать тест
Откройте файл теста в любом текстовом редакторе (или прямо на GitHub кнопкой ✏️). Меняйте **только текст внутри кавычек**. Для каждого типа результата есть:
- `short` — короткая строка,
- `about` — развёрнутое описание,
- `tips` — «Что с этим делать».

⚠️ Не меняйте `type: "..."` у ответов и названия типов (`grandiose`, `covert`…) в уже существующих тестах: по этим ключам хранятся результаты пользователей в базе.

## Как добавить новый тест
1. Скопируйте `data/tests/_template.js` под именем `test6.js`.
2. В первой строке замените `"test_new"` на `"test6"` и поправьте тексты.
3. Добавьте `"test6"` в список в `data/tests-list.js`.
Готово: на сайте появится новая карточка. Картинку к результатам можно подключить строкой `image: "images/файл.jpg"`.

## Фоны результатов
Выбираются автоматически по доле набранных баллов (порог задаётся в `data/config.js`): голубое лето (`bg-good.jpg`) — спокойно, осень (`bg-mid.jpg`) — есть повод присмотреться, тёмно-красный (`bg-bad.jpg`) — выраженные признаки. Картинки можно заменить, сохранив имена файлов.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите **все файлы с сохранением папок** (проще через GitHub Desktop или перетаскиванием папок в «Add file → Upload files»).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ВАШ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## ⚠️ Нюансы Firebase (без этого вход или списки не заработают)
1. **Разрешённый домен.** Firebase Console → Authentication → Settings → Authorized domains → *Add domain* → `ВАШ-НИК.github.io`. Иначе вход через Google выдаст ошибку `auth/unauthorized-domain`.
2. **Google-провайдер** должен быть включён: Authentication → Sign-in method → Google.
3. **Индекс Firestore.** Запрос «Мои результаты» (фильтр по пользователю + сортировка по дате) требует составного индекса. Если при открытии вкладки увидите сообщение про индекс — нажмите F12, в консоли найдите ссылку от Firebase, откройте её и нажмите *Create index*. Подождите 2–5 минут. Если сайт у вас уже работал с такими запросами, индекс уже есть.
4. **Правила базы.** Образец — в `firestore.rules`: пользователь видит только свои результаты, админ (почта из `js/firebase-config.js`) — все. Если ваши текущие правила работают — не трогайте.
5. **Ключ `apiKey` в репозитории — это нормально:** он не секретный, защита делается правилами (п. 4). Дополнительно можно ограничить ключ по домену в Google Cloud Console → APIs & Services → Credentials.
6. **Открывать `index.html` двойным кликом нельзя** — вход через Google работает только по `https://` или `http://localhost`. Для проверки на компьютере: в папке проекта выполните `python -m http.server 8000` и откройте `http://localhost:8000` (домен `localhost` по умолчанию разрешён в Firebase).
7. **Регистр имён файлов важен** на GitHub: `images/bg-good.jpg` ≠ `images/BG-good.jpg`.

## Что изменилось по сравнению со старой версией
- Один вопрос на экран, ответ не выбран заранее (раньше первый вариант был отмечен по умолчанию и мог искажать итог).
- Убрана «постановка диагноза»: формулировки заменены на «черты» и «паттерны», добавлен дисклеймер.
- Результаты стали развёрнутыми: общий итог, диаграммы (шкала, радар, полоски), описание каждого типа с советами.
- В тестах 4 и 5 ответы с «служебными» типами привязаны к существующим типам, поэтому диаграмма теперь согласована с общим баллом. Общий балл считается как раньше.
- Звуки генерируются в браузере (без файлов); кнопка 🔊 в шапке выключает их.
- Сохранён тот же формат записи в Firestore (`test_results`), поэтому старые результаты открываются.
